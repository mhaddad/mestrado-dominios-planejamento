# Registro de uso de IA

Copie uma linha por uso substantivo para a seção 11 do [plano](../plan/plano-revisao-dissertacao.md).

```
| DD/MM/AAAA | Fase | Ferramenta / modelo (versão) | Finalidade | Verificação feita |
```

Exemplo:

```
| 21/09/2026 | 0 | Claude Code (claude-sonnet-5) | Reorganização do repositório e catálogo do acervo | Contagens conferidas por comando; catálogo pendente de revisão do autor |
```

Quando registrar: busca ou triagem de literatura, extração de dados de artigos, geração de código, transcrição de tabelas, rascunho de texto, análise. Não precisa registrar correção ortográfica trivial.

Sempre inclua **o que foi conferido por humano**. "Nada" é resposta válida, mas fica visível.
